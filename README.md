## Search, Retrieval & RAG

* **[Legal Engine Search - LES](https://python-lair.space/pdfs/les.pdf)**
  Designed and evaluated a Spanish legal search engine comparing BM25, dense retrieval, Sentence Transformers, ColBERT, reranking, and LLM consensus.
  [UPM repository (authentication required)](https://oa.upm.es/87939/)

* **[Modular RAG](https://github.com/Intrinsical-AI/rag-prototype)**
  A modular RAG framework based on Ports and Adapters architecture, with interchangeable retrieval, persistence, model-provider, and evaluation components.

* **[Open-source search-quality contributions](https://github.com/SeaseLtd/llm-search-quality-evaluation/commits/main/?author=Intrinsical-AI)**
  Contributions across Vespa integration, Quepid and Docker tooling, tests, typing, Continuous Integration (CI), embeddings, and search-quality evaluation workflows.

* **Domain-specific retrieval experiments**
  Low-Rank Adaptation (LoRA), contrastive learning, and triplet-loss training for legal and healthcare retrieval.
